KEYBOARD COMMANDS

UP ARROW = Moves up cursor in menus/moves ship up.
DOWN ARROW = Moves down cursor in menus/moves ship down.
LEFT ARROW = Chooses level in menu/moves ship left.
RIGHT ARROW = Chooses level in menu/moves ship right.
ENTER = Selects as option.
ESC = Quits to menu while playing.
LEFT CONTROL = Shoots main weapon.
SPACE BAR = Shoots a homing missile (if you have any).

Note that for choosing your starting level, you have to get to
that level in the game first.

WARNING : ALL of the data files must be in a folder called "CG2DATA",
located at the same level the source code ot the executable is in.
In other words, if you have the source stored as C:\QB\CONGEN2.BAS,
there should be another folder called C:\QB\CG2DATA\ in which all
of the data files are stored. Same goes for the executable version.
If you unzip the game keeping directory structure, you should have
no problems.

This is my first full game engine attempt. It is a 2D space shooter,
like the ones popular in the arcades. The gameplay is very simple,
yet fun. It comes with only 2 levels, but it is very easy to make new
ones. Please let me know if you are interested in making your own
levels and background graphics.

The in-game text is in spanish; luckily, the text in this kind of games
is not really important, but anyway:

Main menu
"INICIAR JUEGO" means "BEGIN GAME"
"NIVEL DE INICIO" means "STARTING LEVEL"
"SALIR" means "QUIT"
"MAXIMO PUNTAJE" means "HI SCORE"

In-Game text
"BIENVENIDO A CONGENERATION" means "WELCOME TO CONGENERATION"
"ENERGIA" means "ENERGY"
"ARMA NIVEL X" means "WEAPON LEVEL X"
"MISILES" means "MISSILES" (hard one...)
"CUIDADO POR ATRAS!!!" means "WATCH BEHIND YOU!!!"

Basically, you must destroy enemy ships while avoiding getting
destroyed yourself. At the end of each level, you must face an
evil abomination (a boss). To overcome it, you must destroy each
of its sections. If you succesfully destroy the boss, you go to
the next level.

If all of your energy is gone, so are you. Tough luck. So remember
to catch the health bonuses the enemies sometimes drop when you
blast them. Get the missile boxes and weapon upgrades, too!

The game has been completely programmed in QuickBasic 4.5 with
Angelo Mottola's "DIRECTQB" library version 1.61. If you want to
run or compile the source code, you'll need the library (I think
it is still available in many QB sites). Anyway, I provide the
compiled executable with the archive.

I really hope that QB fans like this game. Please write me an e-mail
if you do, or if you want to report a bug or something. As for me,
the game runs just fine under Windows 9X.

You'll need a SoundBlaster compatible sound card for the game to run
properly. The environment variable "BLASTER" must be properly set to
the values of your sound card (most computers have this variable
correctly set; you shouldn't worry about it).

By the way, some of the sounds come from other games like Worms 2,
GTA2 and Quake 1 and 2. If there is a problem with that, please let
me know.

Have fun and feel free to e-mail me at jhoyos@entelchile.net!

Thanks to Angelo Mottola for his great library, DirectQB!
